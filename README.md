# SHINOBI ATTACK

A 2D pixel-art ninja action game developed with Unity. Fight enemies, dodge dangerous obstacles, and test your reflexes as the challenge gets harder.

🎮 **Play online:** https://florperezcortez-jpg.itch.io/shinobi-attack

## Features

- 2D action and platforming.
- Ninja-themed combat and projectiles.
- Enemies and rolling log obstacles.
- Health system with hearts.
- Progressive difficulty.
- Pixel-art visual style.
- Playable in a web browser.

## Controls

| Key | Action |
|---|---|
| `W` | Jump |
| `A` | Move left |
| `D` | Move right |
| Left mouse button | Shoot |

## Built With

- Unity 6.3 LTS
- C#
- Pixel art assets

## Platform

Web browser (HTML5/WebGL).
